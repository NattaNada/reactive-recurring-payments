3 · Fund the contracts

The RSC pays for its reactive transactions in lREACT; the callback contract pays for callback execution in ETH and holds the payment funds. Both need a balance before the first payment.

Funding uses depositTo() on the system contract / callback proxy so the money becomes spendable reserves. See README.md “Funding”.
